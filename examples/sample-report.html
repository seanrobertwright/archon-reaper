How to read this

  • Success rate is completed runs divided by finished runs (completed, failed, cancelled). A run marked completed can still have an unrecorded outcome; the Completed tile says how many are verified.
  • Total time runs from start to finish and includes time a run sat waiting for approval or between a failure and a resume. Hands-on time subtracts those waits.
  • Failure groups come from keyword rules on the recorded error text, so “Other” means no rule matched.
